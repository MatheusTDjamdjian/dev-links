## 🚀 Technologies
This project was developed with the following technologies:

- HTML and CSS
- JavaScript
- Git and GitHub
- Figma
- Ionicons

## 💻 Project
DevLinks is a link aggregator to be used as an online business card, bringing together my main social media and professional profiles in one place.

`PS: Light and dark mode functionality is implemented.`
